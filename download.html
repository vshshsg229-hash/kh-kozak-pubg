🔊 Про голосові відповіді
Вебверсія озвучує відповіді через голосовий рушій браузера. Щоб вона відповідала на довільні запитання як AI-чат, потрібен налаштований AI-сервер. Android-версія озвучує команди й може давати вільні AI-відповіді після введення HTTPS-адреси захищеного AI-сервера в розділі «Розумні відповіді AI». Без налаштованого сервера працюють підтримувані команди. Голос і якість залежать від установленої мови на пристрої.
📦 Як установити Android APK
  1. Натисни «Завантажити Android APK» — файл APK завантажиться напряму.
  2. Відкрий завантажений app-debug.apk на телефоні й підтвердь установлення, якщо Android попросить.
  3. Якщо посилання ще не працює, дочекайся завершення збірки у GitHub Actions і спробуй знову.
Якщо GitHub попросить увійти або не показує артефакт, відкрий сторінку збірки в браузері й перевір розділ Artifacts.
🖥️ Як установити на ПК
  1. Відкрий цю сторінку в Chrome або Edge через HTTPS.
  2. Натисни «Встановити застосунок», якщо кнопка доступна, або знайди пункт встановлення в меню браузера.
  3. Для Windows-компаньйона окремо завантаж скрипт та прочитай інструкцію. Не запускай скрипти, якщо не довіряєш джерелу.
