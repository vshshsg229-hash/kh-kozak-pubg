# KH么Kozak — план розвитку

## Безпека
- Резервна гілка перед змінами: `backup-before-updates-2026-10-12`.
- Основну гілку `main` змінюємо невеликими перевіреними кроками.
- Після кожного етапу перевіряємо GitHub Pages.

## Поточний сайт
- `index.html` — головна сторінка.
- `videos.html` — відео та посилання на TikTok.
- `avatars.html` — галерея аватарок.

## План етапів
1. Перевірити посилання, шляхи до зображень і мобільне відображення, не змінюючи дизайн без потреби.
2. Додати зручну мобільну сторінку адміністратора для керування посиланнями та контентом.
3. Підготувати публічну галерею кліпів, що використовує посилання на відео TikTok/YouTube замість завантаження великих файлів у GitHub.
4. Перевірити доступність, адаптивність, українську/англійську мови та соціальні посилання.

## Важливо
Не зберігати паролі, токени або секретні ключі у файлах сайту.
