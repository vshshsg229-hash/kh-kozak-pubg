# KH么Kozak Assistant — Android (source starter)
Це вихідний код початкового Android-компаньйона, а не готовий APK.

## Як зібрати APK
1. Установи Android Studio на Windows або інший ПК та відкрий папку `apps/android` як Gradle-проєкт.
2. Дозволь Android Studio завантажити Gradle/Android Gradle Plugin і Android SDK 35.
3. Під'єднай телефон USB або вибери Build > Build Bundle(s) / APK(s) > Build APK(s).
4. На телефоні встановлюй APK лише якщо довіряєш джерелу; Android може попросити дозвіл на встановлення з цього джерела.
5. Запусти KH Assistant, надай дозвіл на мікрофон/сповіщення та натисни «Запустити слухання». Постійне слухання показує системне сповіщення; зупини його кнопкою в застосунку або зупини застосунок у системних налаштуваннях.

## Важливі обмеження
- Це ранній прототип, не перевірений збіркою на фізичному пристрої.
- Розпізнавання залежить від системної служби Android, інтернету/мовного пакета й підтримки української мови.
- Служба використовує більше батареї, ніж спеціалізований низькоенергетичний wake-word engine. Android, виробник телефону та енергозбереження можуть зупиняти фонове слухання.
- Це не дає доступу до всіх програм чи приватних даних. Команди відкривають визначені посилання; системні можливості потребуватимуть окремих явних дозволів.
