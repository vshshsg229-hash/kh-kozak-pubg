# KH么Kozak Assistant — Windows
## Запуск
1. Використовуй Windows PowerShell 5.1 (не обов'язково PowerShell 7).
2. Перевір, що Windows має встановлений український мовний пакет із функцією мовлення/розпізнавання. Якщо його немає, скрипт покаже підказку.
3. Відкрий PowerShell у цій папці й виконай:
   `Set-ExecutionPolicy -Scope Process Bypass`
   `.KH-Kozak-Assistant.ps1`
4. Дозволь доступ до мікрофона, якщо Windows запитає. Залиш PowerShell запущеним. Скажи «Козак, відкрий YouTube» або спочатку «Козак», а потім «калькулятор».
5. Натисни Ctrl+C, щоб завершити.

## Обмеження
Це початковий Windows-компаньйон, що працює, поки процес запущений. Він використовує локальний Windows Speech Recognition і залежить від наявного мовного пакета/мікрофона. Не керує всіма програмами: відкриває лише команди зі списку в скрипті. Для автозапуску Windows потрібно окремо додати його до Startup/Task Scheduler після перевірки.
