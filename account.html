☁ Що синхронізується?

Після підключення хмари сайт передаватиме лише вибрані ключі ігрового прогресу. Історія AI-чату, токени та секретні налаштування не входять у хмарне збереження.

  • ✓Сумісні локальні ключі прогресу, рекордів і внутрішніх нагород.
  • ✓Особисте збереження прив’язане до ID авторизованого акаунта.
  • ✓Правила RLS обмежують читання та зміну даних власником акаунта.
  • !Це не синхронізує інвентар або UC офіційного PUBG Mobile — лише дані сайту.

🛠 Завершення налаштування хмари

  1. ✓Адреса проєкту й публічний Publishable key уже додані в конфігурацію сайту.
  2. 1.Відкрий SQL Editor і виконай вміст файлу account-schema.sql, щоб створити таблицю збережень і правила RLS.
  3. 2.У Supabase → Authentication → URL Configuration додай https://vshshsg229-hash.github.io/kh-kozak-pubg/ як Site URL і Redirect URL.
  4. 3.У Supabase → Authentication → Sign In / Providers увімкни Anonymous Sign-Ins, щоб гостьовий профіль створювався автоматично.
  5. 4.Для спільного рейтингу й друзів виконай community-schema.sql у SQL Editor. Потім відкрий Рейтинг і друзі.
  6. 5.Прив’яжи email і пароль до гостьового профілю, щоб зберегти його при зміні пристрою.

У публічному файлі дозволений лише publishable/anon key з увімкненим RLS. Ніколи не додавай service_role key.
