# KH么Kozak Battle Hub API 8.4

Node.js + PostgreSQL backend for real accounts, shared game rewards, public leaderboard, AI assistant and Telegram webhook. The website itself stays on GitHub Pages; this API must be deployed separately.

## What is server-backed

- Email/password registration and login; passwords are hashed with bcrypt.
- Signed 7-day JWT sessions.
- PostgreSQL accounts, shared coins/points/XP and game counts.
- Server-defined rewards for supported games, event-ID deduplication and a 40-game-reward daily limit.
- Shared top-20 leaderboard.
- Rate limits, input validation, security headers and a database health check.
- Existing optional AI chat and Telegram webhook routes.

The daily shop, cosmetic inventory, secret-code redemption and some missions remain browser-local for now. Do not describe those as server-synced or as secure online rewards yet. Game rewards submitted while signed in are assigned by the server; browser-only/offline play continues using local progress.

## Deploy with Render + PostgreSQL

1. Push this repository to GitHub (these files are already in the existing `backend/` folder).
2. Create a PostgreSQL database with a provider such as Neon, Supabase, or Render. Copy its **pooled/connection** URL as appropriate for that provider. Keep it private.
3. In Render choose **New → Blueprint**, connect `vshshsg229-hash/kh-kozak-pubg`, and select the repository's `render.yaml`. The web service is configured as free; the database URL must be supplied in its environment. If your provider requires SSL, use its provided connection string.
4. In the Render service environment, set `DATABASE_URL` to the database connection string. `JWT_SECRET` is generated by the Blueprint. Save changes and wait for the service to deploy.
5. Open `https://YOUR-SERVICE.onrender.com/api/health`. Continue only when it returns JSON with `"ok": true` and `"database": "connected"`.
6. Copy the public API base URL (no trailing slash). In the site’s **Профіль → Онлайн-сервер** field, paste it and tap **ПІДКЛЮЧИТИ**. The setting is stored only in this browser. The API URL can also be placed in the `kh-api-base` meta tag in `app-v6/index.html` later.
7. Register an account and test login from a second browser/device. The leaderboard will show only users who have registered and earned server-side game rewards.

## Local development

Requires Node.js 20+ and a PostgreSQL database.

1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env` and fill `DATABASE_URL` and a random `JWT_SECRET` (at least 32 characters).
4. `npm start`
5. Open `http://localhost:3000/api/health`.

## Environment variables

- `DATABASE_URL` — required PostgreSQL connection string.
- `JWT_SECRET` — required signing secret, at least 32 characters.
- `FRONTEND_ORIGIN` — allowed frontend origin(s), comma-separated if needed.
- `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` — optional AI-compatible provider settings.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` — optional Telegram integration secrets.

Never put database passwords, JWT secrets, AI keys, or Telegram tokens into frontend HTML/JavaScript. The API does not connect to or modify an official PUBG Mobile account.
