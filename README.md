# KH么Kozak — Project 5.0

Нова мінімалістична версія особистого сайту: тільки профіль, мініігри та музика.

## Відкрити сайт
https://vshshsg229-hash.github.io/kh-kozak-pubg/

## Структура
- `index.html` — перенаправляє на актуальний проєкт.
- `project-5.0/index.html` — головна сторінка.
- `project-5.0/style.css` — стилі та адаптація для телефону/ПК.
- `project-5.0/script.js` — мініігри, редагування профілю та музичний плеєр.

## Що працює
- Профіль можна редагувати; зміни зберігаються локально в браузері цього пристрою.
- Мініігри: «Знайди пару», «Реакція», «Клік-челендж».
- Музика відтворює аудіофайли, які користувач вибирає зі свого пристрою. Файли не завантажуються на сервер.
- TikTok і Telegram відкриваються за посиланнями з профілю.

Це статичний сайт GitHub Pages. Реєстрація з єдиним акаунтом між різними пристроями та серверне зберігання музики не входять до цієї версії.
